> 练习：`exercises/ch01_models_messages.py`　验证：`uv run python check.py 1`

## 1. 关键概念

### 1.1 聊天模型（Chat Model）

LangChain 把各家大模型封装成统一的 `BaseChatModel` 接口。无论 OpenAI、DeepSeek 还是通义千问，用法都一样：

```python
from langchain_openai import ChatOpenAI

llm = ChatOpenAI(model="deepseek-chat", base_url="https://api.deepseek.com/v1", api_key="sk-...")
```

本项目已封装好：`from tutorial_kit import get_llm`，它会读取 `.env` 配置。

> 另一种写法：`from langchain.chat_models import init_chat_model`，`init_chat_model("openai:gpt-4o-mini")`，通过字符串切换模型提供商。

### 1.2 消息（Message）

聊天模型的输入是**消息列表**，每条消息有一个角色：

| 类 | 角色 | 作用 |
| --- | --- | --- |
| `SystemMessage` | system | 设定模型的身份、规则、输出风格。通常放在第一条 |
| `HumanMessage` | human / user | 用户说的话 |
| `AIMessage` | ai / assistant | 模型的回复（`invoke` 的返回值就是它） |
| `ToolMessage` | tool | 工具执行结果（第 3 章） |

```python
from langchain_core.messages import SystemMessage, HumanMessage

messages = [
    SystemMessage(content="你是一位诗人"),
    HumanMessage(content="写一句关于秋天的诗"),
]
```

> 简写：很多地方也接受元组形式 `("system", "...")`、`("human", "...")`。

### 1.3 三种调用方式

所有模型（以及后面所有的 Runnable）都有这三个方法：

```python
ai_msg = llm.invoke(messages)          # 一次调用，返回 AIMessage
print(ai_msg.content)                  # 文本内容
print(ai_msg.usage_metadata)           # token 用量（真实模型才有）

for chunk in llm.stream(messages):     # 流式：逐片返回 AIMessageChunk
    print(chunk.content, end="")

results = llm.batch([messages1, messages2])   # 批量并发调用
```

### 1.4 模型是无状态的

模型**不会记得**上一次调用的内容。要实现多轮对话，必须把历史消息一起发过去：

```python
history = [
    HumanMessage("我叫小李"),
    AIMessage("你好小李！"),
    HumanMessage("我叫什么？"),   # 模型能回答，是因为历史就在输入里
]
llm.invoke(history)
```

第 7 章会用 LangGraph 的 Checkpointer 自动管理历史。

## 2. 使用场景

- 任何需要“问一句、答一句”的功能：问答、改写、翻译、摘要
- 流式输出用于聊天界面，让用户更早看到内容，体验更好

## 4. 常见错误

- `ask` 返回了 `AIMessage` 对象而不是字符串 —— 记得取 `.content`
- 流式输出时把 chunk 对象放进列表 —— 应放 `chunk.content`
